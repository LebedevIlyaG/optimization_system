## Задание 1: Вспомогательные функции (Common.cpp)

### 1.1. GetFileExtension()

**Цель:** Получить расширение файла из полного имени

**Алгоритм:**
1. Найти последнюю точку в строке filename
2. Проверить, что точка не является частью пути (не после '/' или '\\')
3. Вернуть подстроку после точки (с точкой или без в зависимости от параметра)

**Тестовые случаи:**
- "file.txt" → "txt" или ".txt"
- "archive.tar.gz" → "gz" или ".gz"
- "path/to/file.cpp" → "cpp" или ".cpp"
- "makefile" → ""

### 1.2. FindXY()

**Цель:** Найти такие x и y, что x * y * C ≈ z

**Условия:**
- x > y
- x > 5 * y
- Минимизировать |x * y * C - z|

**Алгоритм:**
1. Вычислить приближенное значение y0 = sqrt(z / (2*C))
2. Искать в окрестности [y0 - 10, y0 + 10]
3. Для каждого y вычислить оптимальное x
4. Выбрать пару (x, y) с минимальной разностью

### 1.3. IsBelowGraph()

**Цель:** Проверить, находится ли точка (x, y) ниже графика

**Метод:** Интерполяция Лагранжа

**Опорные точки:**
- (2, 4732.27)
- (3, 5347.42)
- (4, 25636.46)
- (5, 161094.88)

**Формула Лагранжа:**
```
L(x) = Σ(y_i * Π((x - x_j) / (x_i - x_j))) для всех i, где j ≠ i
```

### 2.2. Многомерный случай (N > 1)

#### CalculateNumbr()

**Цель:** Вычислить номер узла s, индекс активной координаты l и вектор направлений v по заданному вектору u

**Алгоритм:**
1. Инициализировать: is = 0, iff = 2^N, k1 = -1
2. Для каждой координаты i:
   - iff = iff / 2
   - k2 = -k1 * u[i]
   - v[i] = u[i]
   - Если k2 < 0, запомнить l1 = i
   - Иначе: is += iff, l = i
3. Обработать специальные случаи (is = 0 или is = 2^N - 1)

#### CalculateNode()

**Цель:** Вычислить вектор u, вектор v и индекс l по номеру узла s

**Алгоритм:**
1. Обработать граничные случаи (s = 0 или s = 2^N - 1)
2. Для каждой координаты разложить s в двоичное представление
3. Вычислить u[i] и v[i] согласно правилам развертки
4. Определить активную координату l

#### GetYOnX()

**Цель:** Получить многомерную точку y по одномерной координате x

**Алгоритм:**
1. Инициализировать y = [0, ..., 0]
2. Для каждого уровня j от 0 до m:
   - Выделить очередные N бит из x
   - Вычислить узел (u, v, l) по этим битам
   - Добавить вклад к координатам y с весом 2^(-j-1)
3. Применить преобразование из [-0.5, 0.5]^N в [A, B]^N

#### GetXOnY()

**Цель:** Получить одномерную координату x по многомерной точке y

**Алгоритм:**
1. Преобразовать y из [A, B]^N в [-0.5, 0.5]^N
2. Для каждого уровня j:
   - Определить, в какой части находится точка
   - Вычислить соответствующий узел
   - Добавить вклад к x с весом 2^(-N*j)

## Задание 3: Метод Пиявского (Piyavsky.cpp)

### Основной цикл Solve()

**Алгоритм:**

```cpp
1. Получить начальные точки (x=0, x=1)
2. Вычислить значения функции в начальных точках
3. Найти лучшую точку

ЦИКЛ пока не выполнен критерий остановки:
    4. Очистить очередь характеристик
    5. Для каждого интервала:
        - Вычислить характеристику R
        - Добавить в очередь
    
    6. Выбрать интервал с максимальной характеристикой
    
    7. Вычислить новую точку:
        x_new = 0.5 * (x_right + x_left) - (z_right - z_left) / (2 * r)
    
    8. Вычислить значение функции в новой точке
    
    9. Разбить интервал:
        - Создать новый интервал [x_new, x_right]
        - Изменить старый интервал на [x_left, x_new]
    
    10. Обновить лучшую точку
    
    11. Проверить критерий остановки:
        - dx = x_right - x_left < eps
        - ИЛИ iterationCount >= maxIterationCount
```

**Характеристика Пиявского:**
```
R = 0.5 * r * (x_right - x_left) - (z_right + z_left) / 2
```

## Задание 4: Алгоритм GSA (GSA.cpp)

### Основной цикл Solve()

**Алгоритм:**

```cpp
1. Получить начальные точки (2 + P точек)
2. Вычислить значения функции ПАРАЛЛЕЛЬНО:
    #pragma omp parallel for num_threads(P)
    for (i = 0 to startPoints.size())
        startPoints[i]->z[0] = task(startPoints[i])

3. Создать начальные интервалы
4. Найти лучшую точку

ЦИКЛ пока не выполнен критерий остановки:
    5. Обновить оценку константы Липшица M:
        M = max{ |z_right - z_left| / dx^(1/N) } по всем интервалам
        Если M = 0, то M = 1
    
    6. Очистить очередь характеристик
    7. Для каждого интервала:
        - Вычислить характеристику R
        - Добавить в очередь
    
    8. Выбрать P интервалов с максимальной характеристикой
    
    9. Для каждого выбранного интервала вычислить новую точку:
        x_new = 0.5 * (x_right + x_left) - 
                sign(z_right - z_left) / (2*r) * |dz/M|^N
    
    10. Вычислить значения функции ПАРАЛЛЕЛЬНО:
        #pragma omp parallel for num_threads(P)
        for (i = 0 to newTrials.size())
            newTrials[i]->z[0] = task(newTrials[i])
    
    11. Для каждой новой точки:
        - Добавить в список испытаний
        - Разбить интервал
        - Обновить лучшую точку
    
    12. Проверить критерий остановки:
        - dx = (x_right - x_left)^(1/N) < eps
        - ИЛИ iterationCount >= maxIterationCount
```

**Характеристика GSA:**

Для внутренних интервалов:
```
R = dx + (z_right - z_left)^2 / (r^2 * M^2 * dx) - 
    2 * (z_right + z_left - 2*z_best) / (r * M)
```

Для граничных интервалов (специальная обработка):
```
R = 2 * dx - 2 * (z - z_best) / (r * M)
```

### Формулы

**Развертка Пеано:**
- Редукция размерности: [0,1]^N → [0,1]
- Плотность развертки: m (обычно 10-15)

**Оценка константы Липшица:**
```
M = max{ |f(y') - f(y'')| / ||y' - y''|| }
```

**Параметр надежности r:**
- r > 1 для гарантированной сходимости
- Обычно r = 2...3
